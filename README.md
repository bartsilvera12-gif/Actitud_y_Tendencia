# Actitud & Tendencia

Sitio web de **Actitud & Tendencia**, boutique de moda femenina.

Diseño exportado desde Claude Design.

## Contenido

- `Actitud y Tendencia - Web.dc.html` — página web (canvas de diseño).
- `support.js`, `image-slot.js` — scripts de soporte del diseño.
- `uploads/Manual_de_Marca_Actitud_y_Tendencia.pdf` — manual de marca.

## Ver la página

Abrí el archivo `Actitud y Tendencia - Web.dc.html` en un navegador.
